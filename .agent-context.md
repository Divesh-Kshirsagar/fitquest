# FitQuest Agent Context

## Codebase Metadata
- **Project Name:** FitQuest
- **Domain:** Gamified Fitness & Geospatial Territory Conquest ("King of the Hill")
- **Mobile Stack:** Kotlin, Jetpack Compose, Material 3, Voyager Navigation & ScreenModels, Orbit MVI, Room Database, Koin DI, Retrofit, MapLibre Native Android, Uber H3 Core
- **Backend Stack:** Python 3.12, FastAPI, SQLModel (SQLAlchemy + Pydantic), asyncpg, Supabase PostgreSQL (PostGIS + H3-pg), Alembic, python-jose JWT
- **Spatial Grid:** Uber H3 (Res 10 for dev/fast testing; Res 9 for production). Visible neighborhood: $k=2$ rings (19 hexes).

## Immutable Schemas & Contracts

### Backend SQLModel Entities
- **User:** `id` (UUID, Supabase Auth PK), `username` (str, unique), `total_lifetime_steps` (int), `total_hexes_captured` (int), `current_streak` (int), `longest_streak` (int), `last_activity_date` (date).
- **HexOwnership:** `hex_id` (str, H3 index PK), `king_id` (UUID, FK -> User.id), `defense_score_steps` (int), `captured_at` (datetime), `times_stolen` (int).
- **RunSession:** `id` (UUID PK), `user_id` (UUID, FK -> User.id), `started_at` (datetime), `ended_at` (datetime), `total_steps` (int).
- **CapturedHex:** `id` (UUID PK), `run_id` (UUID, FK -> RunSession.id), `hex_id` (str), `steps_in_hex` (int).
- **Quest:** `id` (UUID PK), `title` (str), `description` (str), `target_metric` (str), `target_value` (int), `reward_xp` (int).
- **UserQuest:** `user_id` (UUID, FK), `quest_id` (UUID, FK), `current_progress` (int), `is_completed` (bool), `completed_at` (datetime).
- **Friendship:** `requester_id` (UUID, FK), `addressee_id` (UUID, FK), `status` (str: pending/accepted/blocked), `created_at` (datetime).

### Mobile Persistence Schema (Room)
- **CapturedHexEntity:** `hexId` (String, PK), `totalSteps` (Int), `lastUpdated` (Long).
- **UserProfileEntity:** `id` (String, PK: "local_user"), `username` (String), `avatarName` (String), `dailyStepGoal` (Int), `level` (Int), `xp` (Int), `currentStreak` (Int), `longestStreak` (Int), `lastActiveDate` (String: YYYY-MM-DD), `totalLifetimeSteps` (Int), `totalDistanceMeters` (Double), `totalCalories` (Int), `isOnboardingCompleted` (Boolean).
- **RunSessionEntity:** `id` (String, UUID PK), `startedAt` (Long), `endedAt` (Long), `durationSeconds` (Long), `totalSteps` (Int), `distanceMeters` (Double), `caloriesBurned` (Int), `capturedHexCount` (Int), `capturedHexIdsJson` (String), `xpEarned` (Int).
- **DailyQuestEntity:** `id` (String, PK), `title` (String), `description` (String), `targetMetric` (String), `targetValue` (Int), `currentProgress` (Int), `isCompleted` (Boolean), `rewardXp` (Int), `dateString` (String).
- **AchievementEntity:** `id` (String, PK), `title` (String), `description` (String), `category` (String), `iconName` (String), `currentProgress` (Int), `maxProgress` (Int), `isUnlocked` (Boolean), `unlockedAt` (Long?).

### Network DTOs
- `POST /api/v1/runs/sync`: Request payload `RunSyncPayload(total_session_steps: Int, hexes_to_steps: Map<String, Int>)` -> Response `RunSyncSummary(hexes_defended: Int, hexes_stolen: Int, hexes_newly_captured: Int, xp_earned: Int, new_total_lifetime_steps: Int)`.
- `GET /api/v1/map/viewport`: Query params `(min_lat, min_lng, max_lat, max_lng, zoom_level)` -> Response `MapViewportResponse(is_aggregated: Boolean, hexes: List<HexDetailResponse>, heatmaps: List<HeatmapResponse>)`.

## Stable Architecture Requirements Log
1. **Mobile Testing & Validation:** The mobile test suite is executed from `apps/app` using `ANDROID_HOME=/home/dsk/Android/Sdk ./gradlew :app:test`. Note: Gradle root project includes `:app` (pointing to `fitquest/`), so tasks are `:app:<task>`, not `:fitquest:<task>`.
2. **Backend Execution:** The FastAPI server is executed from `apps/api` using `uvicorn app.main:app --reload --host 0.0.0.0 --port 8000`.
3. **Database Environment:** Supabase PostgreSQL with PostGIS and H3-pg. Auth is verified via Supabase JWT Bearer tokens passed to FastAPI dependencies.
4. **Dev Sensor Toggles:** When running on Android emulators lacking hardware `TYPE_STEP_COUNTER` sensors, toggle `useDevSteps = true` and `useDevLocation = true` in `apps/app/fitquest/src/main/java/com/example/mobileapp/di/AppModule.kt`. Always verify both are `false` for production releases.
5. **GeoJSON Offloading:** H3 coordinate-to-boundary calculations and GeoJSON string generation must always be executed on background coroutine dispatchers (e.g. `Dispatchers.Default` or `Dispatchers.IO`) to avoid frame drops on the UI thread.
6. **Git Branching Policy:** Commits must never be made directly on `main`. Feature branches must be created with explicit permission.
